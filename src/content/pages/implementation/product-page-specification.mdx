## 1. Scope

- **In scope:** the product page in both languages, its page-load data, and every interactive element in the wireframe below.
- **Out of scope:** the cart and checkout (separate spec), the site-wide demo banner, and the Event log button.
- **Already live:** page-load data, `view_item`, `add_to_cart`, `add_to_wishlist`, `select_item` and the language switch event. **New in this spec:** a link name on every tracked element (rows marked *Proposed*).

## 4. Link naming convention

Links are named automatically from their **link text**, so the process scales without a list maintained by hand. Link text alone isn't enough: "Shop all" appears in both the menu and the breadcrumb, and every "Add to cart" says the same thing. So each name adds **context**: where the link is, and what it acts on.

**Format:** `region:element:detail…`

<div class="panel note">

**Fixed or changeable?** In this spec, plain words are **fixed**: typed exactly as shown, the same on every page (`pdp`, `add-to-cart`). Words in `{braces}` are **variables**: filled in when the page is built or clicked (`{sku}` → `tg-pk-101`). A developer never invents a fixed part, and never hard-codes a variable.

</div>

| Variable | Filled with | Example |
|---|---|---|
| `{link_text}` | The link's **English** text: lowercase, spaces and symbols to hyphens, `&` to `and` | `packs-and-bags` |
| `{product_name}` | English product name, same rules | `tidepool-daypack` |
| `{sku}` | SKU, lowercase | `tg-pk-101` |
| `{colour}` | English colour name, lowercase | `buoy` |
| `{position}` | Position within its module, counting from 1 | `2` |
| `{to_language}` | Language being switched to | `fr` |

Rules:

- **Regions** come from a fixed list: `header`, `pdp` (product page body), `footer`; other page specs add their own.
- **English on every language version.** On French pages, the English text comes from a `data-link-name` attribute rendered with the page; on English pages, the visible text is used directly.
- **Position only where items repeat** (product grids, lists). Positions shift when layouts change, so a name never depends on position alone.
- **Lowercase, hyphens, colons between parts, 100 characters at most.** Adobe truncates props at [100 bytes](https://experienceleague.adobe.com/en/docs/analytics/implementation/vars/page-vars/prop); the name goes in `prop4`.

## 5. Payloads

**Page load** (already live, unchanged): `page_data_ready` / `page loaded` with the page and `product` objects, then `view_item` / `product viewed`, then `view_item_list` / `product list viewed` for the related products (list `pdp_related`).

**Link click** (new):

```js
// #2, menu link "Packs & bags", on the French page as on the English one
window.lab.ga4({ event: 'link_click', link_name: 'header:nav:packs-and-bags',
                 link_region: 'header', link_url: '/shop/catalog/?category=packs' });
window.lab.adobe({ event: 'link clicked',
                   link: { name: 'header:nav:packs-and-bags', region: 'header', url: '/shop/catalog/?category=packs' } });
```

**Add to cart** (#8: existing event, plus the link name):

```js
window.lab.ga4({ event: 'add_to_cart', link_name: 'pdp:add-to-cart:tidepool-daypack:tg-pk-101',
  ecommerce: { currency: 'CAD', value: 129, items: [{ item_id: 'TG-PK-101', item_name: 'Tidepool daypack',
    item_variant: 'Buoy', price: 129, quantity: 1 }] } });
window.lab.adobe({ event: 'cart add', link: { name: 'pdp:add-to-cart:tidepool-daypack:tg-pk-101' },
  productListItems: [{ SKU: 'TG-PK-101', name: 'Tidepool daypack', quantity: 1, priceTotal: 129 }] });
```

Tag management maps `link.name` / `link_name` to `prop4` and GA4 `link_text`, per the [SDR](/implementation/sdr/). `link_click` and `link clicked` must be added to the site's list of allowed events before they're pushed; the build rejects unregistered names.

## 6. Acceptance criteria

- [ ] Every numbered element except #7 sends exactly one push per click, with the link name in the format above.
- [ ] Link names are identical on `/shop/product/tidepool-daypack/` and `/fr/boutique/produit/sac-de-jour-tidepool/`.
- [ ] #8 sends `add_to_cart` with `value` = price × quantity, and `item_variant` = the selected colour in English.
- [ ] #10 sends `select_item` with `index` and `item_list_id: pdp_related`, and its link name uses the same position, counting from 1.
- [ ] No link name exceeds 100 characters or contains capitals, spaces or accented letters.
- [ ] Nothing is pushed on page load beyond section 5's three events.

QA records the result of each criterion, with the date, in the QA document for this page (in [Data quality](/data-quality/)).
